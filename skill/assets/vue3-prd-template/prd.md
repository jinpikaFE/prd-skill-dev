# 示例功能 PRD

## 1. 功能概述

这是 `$prd` Vue3 原型工作台模板。真实生成时请替换为用户需求对应的功能说明、流程、字段、状态、验收和开放问题。

## 2. PRD 工作台规则

- 左侧使用目录 / 文件结构，目录按功能优先级排列。
- 每个目录第一个文件是 Mermaid 流程图。
- 后续文件展示高保真操作快照和旁侧标注。
- 点击一个文件只展示一个对应画布。
- 拖动画布默认选中，支持滚轮缩放、添加产品标注、添加临时评论、文档预览和下载。
- 标注是产品对原型区域的正式说明；评论是临时评审记录，两者分开展示、分色管理。
- 标注、评论和历史版本删除都需要二次确认。
- 顶部提供发版按钮，发版前需要二次确认；发版后生成 `versions/vX.Y.Z/` 完整目录，写入该版本 `review-data.json`，并在 `versions/index.json` 中形成可切换历史。
- 草稿评审数据写入 `review-data/draft.json`；版本重命名会重命名目录并记录 `renameHistory`；版本删除会删除目录和索引记录。
